# bumdes-desa-sinar-petir

A web-based management and e-commerce system developed for BUMDES Desa Sinar Petir. 
This application is designed to support BUMDES operational activities and provide an integrated e-commerce platform for managing products,
orders, payments, and deliveries.

## Features

### MANAGEMENT SYSTEM
- Admin Dashboard
- User Management
- Seller Management
- Courier Management
- Staff BUMDES Management
- Financial Management
- Reports and Publications

### E-Commerce
- Product Management
- Product Image Management
- Product Catalog
- Shopping Cart
- Checkout
- Order Management
- Payment Management
- Delivery Management

### User Roles

The System supports multiple roles with different access levels :

- **Admin** - Manage and monitor the overall system
- **Staff BUMDES** - Manage BUMDES operational activities
- **Penjual** - Manage products and seller orders
- **Kurir** - Manage delivery activities
- **Pembeli** - Browse products, manage cart, and place orders

### TECHNOLOGIES

- Bootstrap
- Javascript
- HTML5
- CSS3
